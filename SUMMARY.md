# Meteor Dodge

Meteor Dodge is a tiny browser game built from a single prompt: a ship at the bottom dodges falling meteors to score, and one hit ends the game.

## The one prompt

"Build a tiny browser game in a single HTML file: Meteor Dodge. A ship at the bottom moves with arrow keys, meteors fall from the top, dodge them to score, one hit ends the game. Dark space, canvas 2D, no libraries."

## Watch it

The game was filmed as a short video and posted on X for make.fun's "The agent builds a game from one prompt" bounty:

https://x.com/BOSantai/status/2124827540594573371

## How to play

Open index.html in a browser; arrow keys (or A/D, or pointer) move the ship. Dodge the falling meteors — each meteor you dodge scores a point, and one hit ends the game. Press Space to play again.
